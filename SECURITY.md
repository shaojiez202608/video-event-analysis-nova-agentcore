# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues.

Report them privately to the maintainers of the organisation that publishes this
repository, using its documented security contact or private vulnerability
reporting feature (for example GitHub "Report a vulnerability" on the
Security tab, if enabled). If the code is deployed in AWS and you believe you
found a vulnerability in an AWS service, follow the
[AWS vulnerability reporting process](https://aws.amazon.com/security/vulnerability-reporting/).

Include: affected file or component, steps to reproduce, impact, and any
suggested fix. Do not include real video, personal data or credentials.

## Scope

This repository is a prototype for non-production use. See
[SECURITY-NOTES.md](SECURITY-NOTES.md) and [THREAT_MODEL.md](THREAT_MODEL.md)
for the known risks and the hardening list.
